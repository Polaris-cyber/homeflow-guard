# 简历项目描述（公开链接待补）

**HomeFlow Guard｜AI 智能家居自动化编译与安全验证（独立项目）**

- 面向 Home Assistant 初中级用户，设计并实现“设备清单—需求澄清—结构化规则—安全校验—状态仿真—YAML 导出”MVP，明确 AI 生成候选、人确认、程序校验的责任边界。
- 使用 Python、Streamlit、Pydantic 与本地 Ollama `qwen3:14b-q4_K_M`；实现实体/能力允许列表、参数与冲突检查、门锁解锁确认、失败重试和原始运行记录；公开数据全部为合成虚拟家庭。
- 构建并逐条复核 50 条合成场景；冻结版在 35 条锁定测试上端到端成功 31/35（88.6%），同模型直接 YAML 基线 14/35（40.0%）；安全场景阻断 14/14。测试后修复一处“无依据选灯具/亮度”缺口；补丁未重新宣称独立测试成绩。

代码：[GitHub](https://github.com/Polaris-cyber/homeflow-guard)；Demo 待部署。若简历篇幅不足，保留“35 条合成测试”“冻结版”“基线”三个限定词；不能写成真实用户效率提升。3 人可用性测试尚未发生，不写入简历。
