# 简历项目描述（测试集前可信版本）

## 当前可用版本

**HomeFlow Guard｜AI 智能家居自动化编译与安全验证（独立项目）**

- 面向 Home Assistant 初中级用户，设计“设备清单—需求澄清—结构化规则—安全校验—状态仿真—YAML 导出”闭环，明确 AI、确定性程序和用户的责任边界。
- 使用 Python、Streamlit、Pydantic 与本地 `qwen3:14b-q4_K_M` 实现可运行 MVP；通过允许列表、参数范围、冲突/循环检测和敏感动作确认阻断未知实体及危险配置，并保留 Prompt、模型 digest、延迟与失败输出。
- 建立 50 条合成场景、直接 YAML 基线、可复算评测脚本和自动化测试；首轮逐条复核发现 10 条标注问题并修订，保留旧版本与失败记录；35 条锁定测试集与小样本可用性测试待完成。

## 最终定稿替换规则

完成数据复核、锁定测试和真实用户测试后，第三条可替换为最终样本规模、端到端成功率、相对基线百分点、关键安全指标和用户任务完成情况。不得把旧标注开发集的 40.0 个百分点差值写成当前或独立测试结果，也不得把尚未完成的用户测试写入简历。
