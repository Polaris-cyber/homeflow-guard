# 隐私与安全说明

## 数据处理

- 应用没有数据库、账号或长期存储。
- 上传的设备清单仅保存在当前 Streamlit 会话内存。
- 本地 Ollama 模式通过 `127.0.0.1` 调用模型，不向外部模型服务上传内容。
- 公开仓库与 Demo 只包含合成设备、合成状态和合成需求。

## 禁止上传

不要上传 Home Assistant Token、API Key、密码、真实家庭地址、经纬度、住户姓名、摄像头内容或未经授权的公司资料。解析器会拒绝常见敏感字段，但自动检测不能替代人工审核。

## 安全边界

HomeFlow Guard 不连接真实设备。门锁解锁需要明确确认，存在阻断问题时不生成可下载 YAML。任何导出仍需在隔离环境人工检查；项目不对真实设备或人身财产安全承担自动化决策责任。
