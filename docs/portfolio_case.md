# 一页式作品集案例结构

## 01 问题

用户会描述场景，但不熟悉 Home Assistant 语法；直接生成 YAML 缺少设备约束、风险控制和可解释调试。

## 02 目标用户与任务

目标用户、关键任务、现有流程、失败成本；只使用公开/合成证据，不虚构访谈。

## 03 产品闭环

设备清单 → 自然语言 → AutomationIR → 校验 → 仿真 → YAML。用一张流程图解释 AI、程序和用户的责任边界。

## 04 核心设计

- 严格 schema，而非自然语言中间结果。
- 设备能力与服务允许列表。
- Fail-closed 安全检查和敏感动作确认。
- 可解释状态 Trace。

## 05 评测

展示数据集组成、基线、最终方案、模型完整版本、真实指标和置信边界。单独标记合成集结果与用户测试结果。

## 06 失败与迭代

选 2–3 个真实失败案例：歧义遗漏、实体幻觉、参数越界或结构失败。展示原因、修复和仍未解决的问题。

## 07 结果与边界

放置 Demo、GitHub、视频链接；说明不接真实设备、语法子集和小样本限制。
