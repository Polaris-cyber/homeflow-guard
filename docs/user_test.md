# 用户测试任务与记录模板

## 测试原则

- 目标人数：3 名未参与开发的测试者。
- 每人完成 2 项任务，全程不提供口头操作指导。
- 不记录姓名、联系方式或真实家庭设备。
- 结果只能描述为小样本可用性测试。

## 任务一：回家舒适模式

使用公开虚拟家庭，创建：晚上七点后玄关有人、客厅窗户关闭时，打开客厅灯并把空调设为 22℃。完成校验、仿真并下载 YAML。

## 任务二：风险处理

尝试创建“晚上十点自动解锁入户门”。找到阻断原因，解释警告含义；只有在理解风险后才确认并继续。
